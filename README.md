### Описание программы
Консольная программа на C++ для подсчета магической энергии при призыве армии скелетов. Приложение запрашивает текущий запас маны и стоимость призыва одного юнита, после чего считает максимальный размер отряда и остаток энергии после каста.

**Что умеет программа:**
- Считает количество призванных скелетов через целочисленное деление (`/`).
- Вычисляет остаток маны с помощью остатка от деления (`%`).
- Проверяет введенные числа (не дает ввести отрицательную ману или нулевую цену призыва).
- Выводит статус ритуала в зависимости от того, хватило ли энергии хотя бы на одного воина.

**Формулы расчета:**  
`Размер армии = Текущая мана / Стоимость призыва`  
`Остаток маны = Текущая мана % Стоимость призыва`

### Сборка и запуск

Компиляция и запуск через терминал:

```bash
g++ main.cpp -o necromancer
./necromancer
```

### Примеры работы

#### Тест 1: Обычный призыв
* **Ввод:** мана = `250`, стоимость = `35`
* **Вывод:**
```text
--- КАЛЬКУЛЯТОР ПРИЗЫВА СКЕЛЕТОВ ---

Введите текущий запас маны: 250
Введите стоимость призыва одного скелета: 35

[РИТУАЛ ЗАВЕРШЕН] Армия призвана!
Максимальный размер армии: 7 скелетов.
Остаток маны: 5 ед.
```

#### Тест 2: Не хватает маны
* **Ввод:** мана = `20`, стоимость = `50`
* **Вывод:**
```text
--- КАЛЬКУЛЯТОР ПРИЗЫВА СКЕЛЕТОВ ---

Введите текущий запас маны: 20
Введите стоимость призыва одного скелета: 50

[ВНИМАНИЕ] Недостаточно маны для призыва даже одного скелета.
Максимальный размер армии: 0 скелетов.
Остаток маны: 20 ед.
```

#### Тест 3: Ошибка ввода
* **Ввод:** мана = `100`, стоимость = `0`
* **Вывод:**
```text
--- КАЛЬКУЛЯТОР ПРИЗЫВА СКЕЛЕТОВ ---

Введите текущий запас маны: 100
Введите стоимость призыва одного скелета: 0

[ОШИБКА] Мана не может быть меньше нуля, а стоимость призыва должна быть больше нуля.
```
